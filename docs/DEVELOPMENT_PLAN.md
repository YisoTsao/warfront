## 2. 每個階段的工作流程

依主規格 §17：檢查 repo 與工具 → 閱讀文件與資產 → 找可重用的部分 → 寫小型實作計畫 → 實作一個完整的垂直切片 → 型別檢查與 lint → 相關的單元與整合測試 → 本機啟動用戶端（與伺服器） → **在真實瀏覽器驗證行為** → 多人功能用多個瀏覽器測試 → 修正錯誤 → 更新文件並回報驗證結果。

不能因為「檔案已產生」就宣稱完成；完成需要建置成功並實際測試過行為。

### 3.2 效能量測

| 項目 | 數值 |
|---|---|
| 測試機 | 雲端容器，4 核心、15 GB RAM，**無 GPU** |
| 瀏覽器 | Chromium 1.63 headless |
| 渲染器 | WebGL 2 on SwiftShader（軟體繪圖） |
| 解析度 | 1280×720 |
| FPS | 約 4–6 FPS（畫格時間約 170–250 ms） |
| Draw calls | 約 50–70 |
| 三角形 | 約 600–800 |
| 下載量 | 外殼 228 KB（gzip 72 KB）；遊戲 chunk 4.9 MB（gzip 1.8 MB，大部分是 Rapier WASM） |

**這組 FPS 不能作為效能結論**：軟體繪圖完全由 CPU 處理，與實際玩家的 GPU 環境無關。場景本身很輕（draw calls 不到 100），但 60 FPS 目標仍必須在參考 PC 上量測後才算驗收。

### 3.3 已知限制

- 效能未在有 GPU 的參考 PC 量測。
- 只測了 Chromium；Firefox 依主規格在第一個里程碑之後測試。
- 無頭 Chromium 在 Pointer Lock 下會把游標拉回中心，Playwright 的 `mouse.move` 淨位移為 0，因此視角測試改派送帶有 `movementX/Y` 的 `mousemove` 事件（仍經過實際的輸入處理）。真實滑鼠需要在有畫面的瀏覽器手動確認。
- 臥倒尚未實作（主規格：基本移動與碰撞穩定後再做）。
- 按鍵綁定為資料驅動，但還沒有重新綁定的 UI。
- 遊戲 chunk 偏大（Rapier WASM 以 base64 內嵌）。
- 下一個階段之前沒有畫質等級（Low / Medium / High）與動態解析度。

### 3.4 Phase 1 中修正的問題

開發過程中，瀏覽器測試抓到並修正了以下問題：

1. **爬坡時速度一路下降**：原本把實際位移 ÷ dt 當成下一步的速度。Rapier 在坡面上會縮短水平位移，形成回饋，40° 坡上速度掉到 0.43 m/s。改為分開「預期速度」與「實際速度」。
2. **上樓梯卡在第一階**：撞到台階立面時若把預期速度歸零，Rapier 的自動跨步就不會觸發。改為地面上不修正預期速度，只在空中移除被牆擋住的分量。
3. **設定滑桿沒有正確標籤**：`<label>` 包住 `<output>` 與 `<input>`，標籤實際指向 `<output>`。改為 `htmlFor` 指向滑桿。
4. **低 FPS 時模擬變慢**：每畫格最多補 8 步，FPS 低於 7.5 時模擬落後實際時間。改為補到 0.25 秒（15 步）。

## 4. 下一步建議

**建議下一個任務：Phase 3（武器與單機戰鬥原型）**，同時請專案負責人提供 Phase 2 需要的資料。

理由：Phase 2 被 Blackwood Valley 原始檔卡住，而 Phase 3 只需要灰盒場景；武器數值可以直接沿用舊版 UE5 骨架（`legacy/ue5/Source/Frontline/Data/FLDefaultContent.cpp`）。依主規格 §5.4，先做一把突擊步槍與一把手槍、一套換彈與 ADS 流程，以及可以接上伺服器驗證的 hitscan 開火路徑。

若專案負責人希望嚴格依階段順序，則先提供原始檔並進行 Phase 2。

## 5. 待確認事項

需要專案負責人決定或提供：

1. **Blackwood Valley 原始檔**與 Blender 版本（Phase 2 的阻礙）。
2. **參考 PC 規格**：CPU、GPU、RAM、瀏覽器版本、解析度。效能目標以此為驗收依據。
3. **舊版 UE5 骨架**（`legacy/ue5/`）的保留期限。建議保留到 Phase 7 的數值移植完成後再刪除。
4. **帳號系統**是否在 MVP 啟用（影響 Phase 4 用正式 Supabase Auth 還是開發用訪客身分）。
5. **部署環境**：靜態網站（Vercel 或 Cloudflare Pages）與遊戲伺服器的主機（需要常駐的程序或容器，不能是 serverless function）。
