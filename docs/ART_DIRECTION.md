# 美術方向

> 依據：`FRONTLINE_WEB_PROJECT_SPEC.md` §0、§8.1、§8.6、§13。

## 1. 方向

寫實的現代軍事戰場，參考 Battlefield 系列的視覺語言：可信的材質、自然光、溫帶森林地形與有重量感的武器回饋。

**範圍界線**：「像 Battlefield」描述的是美術方向與戰鬥體驗，不代表瀏覽器版能達到原生 AAA 遊戲的渲染品質、規模、破壞、動畫複雜度或效能。第一個目標是穩定、好看、真正可玩的 8v8 瀏覽器 FPS；只有在畫格時間與網路預算都健康時才提高畫質。

## 2. 環境：Blackwood Valley

- 溫帶森林、山脈、河谷、岩石地形。
- 林道、橋梁、廢棄聚落。
- 軍事據點與目標。
- 自然與人造掩體。

## 3. 光照與材質策略

瀏覽器不追求重現 UE5 專屬功能（Lumen、Nanite、Virtual Shadow Maps），改用混合做法：

| 項目 | 做法 |
|---|---|
| 材質 | PBR，roughness / metalness 數值一致 |
| 天空 | 高品質天空與大氣霧 |
| 陽光 | 控制良好的方向光 |
| 靜態環境 | 盡量烘焙光照與環境光遮蔽 |
| 動態陰影 | 優先給附近的玩家與重要物件 |
| 後處理 | 選擇性使用；預設不開昂貴的全螢幕效果 |
| 水 | 只在看得到且影響玩法的地方用高品質水面 |
| 變化 | 材質與植被要有足夠變化，避免明顯重複 |

優先順序：構圖、光照、材質反應、植被品質、地形細節、受控的可視距離。

## 4. 畫質等級

提供 Low / Medium / High 三種預設，並在需要時動態降低：渲染解析度、陰影品質、植被密度、後處理。具體預算在參考 PC 確定後填入（見 `DEVELOPMENT_PLAN.md`）。

## 5. 介面

一致的現代軍事戰術風格，選單必須能完全以鍵盤與滑鼠操作。Phase 1 的選單使用深色半透明面板、金色強調色（`#c8a24a`），之後的 HUD 與大廳沿用同一組色彩與字體。

## 6. 音效與特效

依主規格 §13：依武器類型的槍聲、換彈與操作聲、依地面材質的腳步聲、近距與遠距槍聲分層、子彈飛過與命中聲、爆炸、環境音、空間化音效；槍口火光、曳光彈、依材質的命中效果、煙與爆炸、彈殼、水花、塵土與碎片、受傷回饋。頻繁產生的粒子一律使用物件池，戰鬥中不大量建立與銷毀 GPU 資源。

## 7. 目前的暫代資產

在美術資產完成前，以下都是程式產生的暫代品。資料欄位已預留，載入程式待資產到位時加入：

| 項目 | 暫代做法 | 替換方式 |
|---|---|---|
| 第一人稱武器 | 依武器數值拼出的方塊與圓柱（`Viewmodel.ts`） | 武器資料預留 `presentation.modelPath`（glTF） |
| 士兵 | 骨架 glTF（Quaternius SWAT，CC0）與 AK 步槍（Quaternius，CC0）；持槍待機、走、跑、死亡用模型動畫，蹲下、臥倒與雙手握槍由程式 IK 疊加；隊伍以制服顏色與臂章區分。風格偏低多邊形 | 換成更寫實、有蹲走／臥倒／爬行／換彈動畫的角色；`SoldierModel` 對外介面不變 |
| 音效 | WebAudio 合成（槍聲分層、遠處低通與音速延遲、腳步聲依材質） | 武器資料預留 `presentation.fireSound`、`reloadSound`（音檔） |
| 地圖 | 森林谷地：Blender 程序化產生的地形、樹木、岩石、建築（材質由程序化顏色換成固定顏色；地形用 2048² 底色貼圖）；水面用 Blender 的流向與水深資料做動態 shader；物理天空與環境光、動態雲層；GPU 草地（依 Blender 草與花密度） | 在 Blender 把程序化材質烘焙成貼圖後重新匯入；地形細節貼圖 |

## 8. Phase 1 灰盒

灰盒地圖只用來驗證移動與碰撞，刻意使用素色與 2 m 格線，方便判斷速度與距離。顏色依用途區分：地面（綠灰）、坡道（土黃）、方塊與平台（灰）、掩體（藍灰）、通道頂（褐）。這不是最終美術。
